We added seven randomly initialized BERT-style MLM encoders trained with a shared, prespecified 2B-input-token protocol. We evaluate the same 256 held-out documents using the original CFS intervention and alpha grid, with input-paired bootstrap intervals. Across width 384/512/640, Matched-2 increases (0.06961 → 0.08624 → 0.09598), whereas depth 6/8/12 exhibits a non-monotonic pattern (0.09431 → 0.08624 → 0.10459). With exactly 41,404,730 parameters, changing the head decomposition from 4 to 8 to 16 yields Raw Oracle 0.15046 → 0.17287 → 0.16960 and Matched-2 0.11845 → 0.08624 → 0.05571. We also report fixed-K=4 graph controls. These results extend controlled CFS analysis to bidirectional encoders, without establishing universal monotonic scaling or causal performance benefits. The common-input 1B/2B probes show residual functional drift in some models, so we describe the results as equal-budget comparisons rather than fully converged functional organization. All intervals condition on one training seed; they do not measure across-training variability.
